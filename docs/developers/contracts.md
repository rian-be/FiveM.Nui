# Automated DTO Contracts (`FiveM.Nui.Contracts`)

> **Eliminate manual type duplication between C# and TypeScript and prevent runtime bugs caused by typos in event names.**

---

## 1. How the Contract Generator Works

The `FiveM.Nui.Contracts` Roslyn tool inspects your compiled C# assemblies and generates a TypeScript module (`contracts.ts`):
1. **C# records** are mapped to TypeScript `interface` types.
2. **C# XML documentation comments (`/// <summary>`)** are converted to IDE-friendly TSDoc comments.
3. Properties in `PascalCase` are converted to `camelCase` (matching `NuiJsonSerializer`).
4. Generates module augmentation for `declare module '@fivem-nui/core'` with strongly typed `NuiEventMap`.

---

## 2. Defining Contracts in C#

In `src/Shared/Contracts.cs`, use the contract attributes:
* `[NuiContract]` — marks a class or record as a contract type.
* `[NuiEvent("event_name")]` — maps a request or event payload to a string event key.

```csharp
using FiveM.Nui.Abstractions.Contracts;

namespace MyResource.Shared;

/// <summary>Single item in the shop catalog.</summary>
[NuiContract]
public sealed record ShopItemDto(
    string Id, 
    string Name, 
    int Price, 
    int Stock
);

/// <summary>Initial state pushed when NUI boots.</summary>
[NuiContract]
[NuiEvent("shop:catalog")]
public sealed record CatalogDto(
    string PlayerName, 
    int PlayerMoney, 
    ShopItemDto[] Items
);

/// <summary>Purchase request sent from NUI to C#.</summary>
[NuiContract]
[NuiEvent("shop:buy")]
public sealed record BuyRequest(
    string ItemId, 
    int Quantity
) : INuiRequest<BuyResponse>;

/// <summary>Purchase response returned from C# to NUI.</summary>
[NuiContract]
public sealed record BuyResponse(
    bool Success, 
    string Message, 
    int RemainingMoney
);
```

## 3. Generated TypeScript File (`contracts.ts`)

After running the generator, `web/src/contracts.ts` contains:

```ts
// <auto-generated>
//   This file was generated by FiveM.Nui.Contracts from C# contract types.
// </auto-generated>

export interface ShopItemDto {
  id: string;
  name: string;
  price: number;
  stock: number;
}

export interface CatalogDto {
  playerName: string;
  playerMoney: number;
  items: ShopItemDto[];
}

export interface BuyRequest {
  itemId: string;
  quantity: number;
}

export interface BuyResponse {
  success: boolean;
  message: string;
  remainingMoney: number;
}

declare module '@fivem-nui/core' {
  interface NuiEventMap {
    "shop:buy": { request: BuyRequest; response: BuyResponse };
    "shop:catalog": { payload: CatalogDto };
  }
}
```

## 4. Automation Workflow (CLI & MSBuild)

### Option A: Manual CLI execution
Inside the `web/` folder, add a script to `package.json`:
```json
"scripts": {
  "contracts": "dotnet run --project ../../tools/FiveM.Nui.Contracts -- -a ../src/Shared/bin/Release/net10.0/MyResource.Shared.dll -o src/contracts.ts"
}
```

### Option B: Automatic generation on `dotnet build`
In `MyResource.Shared.csproj`, configure automatic output:
```xml
<PropertyGroup>
  <GenerateDocumentationFile>true</GenerateDocumentationFile>
  <GenerateNuiContracts>true</GenerateNuiContracts>
  <NuiContractsOutput>$(MSBuildProjectDirectory)\..\web\src\contracts.ts</NuiContractsOutput>
</PropertyGroup>
```
Whenever you build your C# project, `contracts.ts` is updated instantly.
